## Descripción
Plataforma de analítica y gestión institucional orientada a medir, procesar y mitigar el desgaste emocional o burnout y el clima organizacional en el hospital regional, garantizando el anonimato absoluto del personal asistencial y administrativo mediante un motor de supresión de muestras críticas, integración no invasiva con sistemas legacy estatales como el SIGA y INFORHUS y autenticación centralizada mediante Keycloak.  
 ## Caso de estudio
Sistemas de evaluación de clima organizacional y tableros analíticos institucionales del sector salud como referencia funcional.
