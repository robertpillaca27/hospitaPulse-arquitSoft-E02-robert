| Actor | ¿Qué necesita realizar? |
| :--- | :--- |
| **Personal Asistencial** | Responder encuestas de pulso y clima laboral, pausar/completar evaluaciones y consultar el estado de sus envíos de forma anónima. |
| **Personal Administrativo** | Responder evaluaciones de clima organizacional y cultura institucional adaptadas a su régimen laboral. |
| **Jefe de Departamento** | Consultar tableros consolidados e indicadores de burnout y clima laboral de su área (con restricción de muestra mínima $N \ge 5$). |
| **Unidad de RRHH** | Crear y gestionar encuestas, estructurar el organigrama hospitalario (CAP/PAP), monitorear participación y exportar reportes para DIRESA/MINSA. |
| **Dirección General** | Consultar métricas ejecutivas consolidadas del clima organizacional del hospital para la toma de decisiones estratégicas. |
| **Administrador de TI** | Administrar usuarios, gestionar roles y permisos (RBAC), supervisar la integración SSO y configurar las ejecuciones de procesos ETL. |
| **Servicio de Identidad (Keycloak)** | Autenticar usuarios de forma centralizada mediante SSO y gestionar credenciales y tokens OAuth2 o OIDC. |
| **Sistemas Legacy (SIGA / INFORHUS)** | Proporcionar información de personal, plazas CAP y PAP, además de datos de la estructura organizacional. |
