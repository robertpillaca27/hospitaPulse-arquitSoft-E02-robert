| ID | Restricción | Descripción |
| :--- | :--- | :--- |
| **RC01** | Aplicación Web Responsive | El sistema debe desarrollarse como una aplicación web accesible desde navegadores móviles, tablets y PCs de escritorio. |
| **RC02** | Sistemas Legacy Internos | El sistema debe operar de forma no invasiva frente a los sistemas del Estado (SIGA, SIAF, INFORHUS, GALENOS), consumiendo datos solo en modo lectura o archivos de intercambio. |
| **RC03** | API REST | La comunicación entre la interfaz de usuario (Frontend) y los servicios del backend debe realizarse mediante un protocolo REST o JSON. |
| **RC04** | Servicio de Autenticación SSO | El sistema debe delegar la gestión de identidades a un servidor Keycloak mediante el estándar OAuth2 o OIDC. |
| **RC05** | Normativa de Protección de Datos | El tratamiento de datos debe alinearse estrictamente a la Ley de Protección de Datos Personales (Ley N° 29733). |
