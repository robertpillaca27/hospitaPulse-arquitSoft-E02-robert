| ID | Atributo de calidad | Escenario de calidad |
| :--- | :--- | :--- |
| **AC01** | Seguridad y Privacidad | Las respuestas de los cuestionarios deben ser completamente anónimas y no trazables hacia ningún trabajador, suprimiendo reportes con muestras pequeñas ($N < 5$). |
| **AC02** | Usabilidad | Las encuestas deben ser intuitivas, responsivas y completarse en menos de 3 minutos desde cualquier terminal médica o móvil. |
| **AC03** | Disponibilidad | El sistema debe permanecer disponible durante los turnos de guardia (24/7) en la red interna del hospital para asegurar la participación del personal. |
| **AC04** | Rendimiento | La consulta de tableros de control y la carga de cuestionarios deben responder rápidamente sin degradar la red interna del hospital. |
| **AC05** | Mantenibilidad | El sistema debe permitir actualizar la estructura organizativa y agregar nuevos tipos de evaluaciones sin alterar el historial de datos previos. |
